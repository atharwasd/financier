Financier

Financier is a personal finance tracker for Windows and Android, built for a single user's own use. It tracks accounts, spending, budgets and planned payments. Receipts and statements are read by an AI model running on the user's own computer.

Data syncs between the user's devices through a hidden app-data folder in the user's own Google Drive.
